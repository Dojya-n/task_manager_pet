# Task Manager

Простая консольная утилита похожая на блокнот

## Возможности
- Добавление задач
- Удаление задач
- Завершение задач
- Просмотр всех задач с фильтрацией
- Поиск по названию и описанию
- Сохранение между запусками (JSON)

## Запуск
```bash
python task_manager.py
```

## Использование
1 - Добавить задачу
2 - Удалить задачу (нужен ID)
3 - Завершить задачу (нужен ID)
4 - Вывести все задачи
5 - Найти задачу
0 - Выход

## Технологии
- Python 3.11
- json
- datetime
